# Responsive Personal Portfolio Website (CSS Advanced) - Lab 3

## Project Description
This project is a modern, one-page responsive personal portfolio website built as part of the Web Dev I Lab Assignment 3. It showcases my personal information, education, skills, and projects using advanced CSS features like Flexbox, CSS Grid, media queries, keyframe animations, and smooth transitions.

## Features & Technologies Used
* **HTML5 & CSS3**: Structured semantic elements and modern styling.
* **Flexbox**: Used for aligning and spacing elements in the header and hero sections.
* **CSS Grid**: Used to arrange skill cards and project cards neatly into responsive rows and columns.
* **Relative Units**: Utilized `rem`, `em`, `vw`, and `vh` for scalable typography and consistent spacing.
* **Animations & Interactivity**: Added a color-changing keyframe animation to the title and smooth hover transitions on buttons and cards.

## Responsive Design & Breakpoints Tested
The website is fully responsive and adapts seamlessly across multiple screen sizes:
* **Desktop Screens (> 768px)**: Displays a multi-column side-by-side hero layout and multi-item grid layouts.
* **Tablet & Mobile Screens (<= 768px)**: Uses media queries to stack the hero elements (text above the profile image) and adjusts navigation links for optimal mobile viewing.

## How to View
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
